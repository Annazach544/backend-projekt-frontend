## Bistro Anna - Frontend

Detta projekt är frontend-delen av Bistro Anna, en restaurangwebbplats skapad med Angular.

Webbplatsen använder en REST-baserad webbtjänst för att hämta och visa restaurangens meny.

## Funktioner
- Visa restaurangens meny
- Presentation av restaurangen
- Bokningssida
- Administrationsgränssnitt för inloggning
- Responsiv design

## Teknologier
- Angular
- TypeScript
- HTML
- CSS
- HttpClient
